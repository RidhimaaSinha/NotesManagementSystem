MyNotesApp 📝

A simple full-stack notes application built with the MERN stack with a clean responsive UI to help you manage and organize your notes.

✨ Features

Create Notes — Add notes with a title and content.

View Notes — Display all saved notes on the home page.

Edit Notes — Update existing note details.

Delete Notes — Remove notes when they're no longer needed.

Individual Note View — Open a specific note using its unique ID.

Responsive UI — A clean interface built with React, Tailwind CSS, and DaisyUI.

REST API — Communicate with the backend through Axios.

## 🛠️ Tech Stack

### Frontend
- **React.js** – Building the user interface
- **Vite** – Frontend development server and build tool
- **Tailwind CSS** – Styling and responsive layouts
- **DaisyUI** – Prebuilt UI components and themes
- **React Router** – Client-side navigation
- **Axios** – HTTP requests to the backend API
- **React Hot Toast** – Success and error notifications
- **Lucide React** – Icons

### Backend
- **Node.js** – JavaScript runtime
- **Express.js** – Backend server and REST API
- **MongoDB** – NoSQL database for storing notes
- **Mongoose** – MongoDB object modeling and schema validation
